# Session2Task
C# - Project

1- To Run The Project:
- Open Program.cs on Session2Task Folder.
- press f5
- To Test Any Task Remove "//" , not "//-" it's comment!

2- Tasks Description:

  Task7(); -Calculator

  Task9 [3 Methods]: -Area(Overloading) | Argument: Circle => Area (double) | Rectangle => Area (double, double) | Triangle => Area (double, double, double).

  Task(10): -Find the bugs | Argument: Sum(int).
  -> ctrl + shift + D => show Locals Window, F5 => to Debugging, F9 => To Put a Breakpoint, f10 => to Step & run Line by Line.
